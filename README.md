# TheDesk mobile

(Old name: TootDesk)

The new generation of Mastodon client for iOS!!


## Get Started on Simulator

```
yarn
yarn ios
```

## Build

```
yarn
yarn build
```

## Push notification

Check: [cutls/TootDesk-push-server](https://github.com/cutls/TootDesk-push-server)

If you wish to use it as-is, please rebuild TheDesk mobile in your own Expo account.

This software is hosted at `push.thedesk.top` only for official TheDesk mobile. If you rebuild TheDesk mobile yourself, you must host this project or compatible software yourself at your domain and subscribe to push notifications for that domain.
